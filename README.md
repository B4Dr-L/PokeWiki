# PokeWiki

A lightweight Pokemon browser built with React and Vite, using the PokeAPI to fetch and display Pokemon in a grid.

[Live Demo](https://B4Dr-L.github.io/PokeWiki)

## Features

- Browse Pokemon in a grid with pagination
- Filter by type
- View Pokemon details, shiny forms, and cries
- Build and manage a team list

## Tech

- React
- Vite
- Tailwind CSS
- PokeAPI

## Setup

```bash
npm install
npm run dev
```
